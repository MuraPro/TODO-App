# 📝 To-Do List Application

## 🎮 Project Overview

This To-Do List application is designed to manage tasks efficiently. The project is divided into two branches:

- **`main`**: Implements the application using class components.
- **`hooks`**: Implements the application using functional components with React Hooks.

Both implementations provide the same core functionality, allowing developers to explore and compare different approaches in React development.

## 🛠 Technologies Used

- **Frontend**: React.js, JavaScript (ES6+), HTML5, CSS3
- **State Management**: `useState`, `useEffect` (in the `hooks` branch)
- **Styling**: CSS3, Flexbox
- **Data Persistence**: LocalStorage
- **Deployment**: Netlify

**Live Demo:** [https://snazzy-capybara-024fb8.netlify.app/](https://snazzy-capybara-024fb8.netlify.app/)
